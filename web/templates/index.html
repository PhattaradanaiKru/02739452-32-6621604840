เลือกเมืองเพื่อเปรียบเทียบข้อมูลแต่ละแหล่ง

#เมือง / รหัสเทศบาลจังหวัดประชากร (คน)ปีข้อมูลแหล่งข้อมูลพิกัด

เลือกค่าประชากรตามลำดับ e-Stat → UNdata → GeoNames ค่าที่ไม่มีปีสำมะโนจะแสดงว่า “ไม่ระบุปี” ชุดข้อมูลครอบคลุมเฉพาะเมืองที่รวบรวมได้ ไม่ใช่ประชากรทั้งประเทศ ชื่อเมืองคงรูปสะกดตามต้นทางเพื่อใช้อ้างอิง

การทำงานของระบบ

ติดตามการรวบรวมข้อมูล

ประวัติการทำงานและสถานะแต่ละแหล่ง อ่านจาก PostgreSQL โดยตรง

เตรียมระบบ→ดึง 3 แหล่งพร้อมกัน→รวมและตรวจสอบ→ตัดสินคุณภาพ→บันทึกหรือแยกตรวจ

ประวัติการทำงานล่าสุด

รหัสรอบการทำงานสถานะจำนวนเมืองรายการที่ไม่ผ่านเริ่มเมื่อสิ้นสุดเมื่อ

สถานะ “สำเร็จบางแหล่ง” หมายถึงเผยแพร่ข้อมูลที่ผ่านเกณฑ์จากแหล่งที่ยังใช้งานได้ หาก GeoNames ล่มหลังเคยรวบรวมสำเร็จ ระบบจะใช้พิกัดเดิมพร้อมรักษาเวลาดึงเดิม หากฐานข้อมูลยังว่างและไม่มีพิกัดเพียงพอ ระบบอาจไม่ผ่านเกณฑ์คุณภาพ

ความน่าเชื่อถือและการตรวจสอบ

ตรวจข้อมูลก่อนเผยแพร่

แสดงผลตรวจคุณภาพและรายการที่จับคู่ไม่ได้ พร้อมรักษาชุดข้อมูลเดิมเมื่อไม่ผ่านเกณฑ์

ข้อมูลผ่านเกณฑ์อย่างน้อย 100 เมืองประชากรมากกว่าศูนย์พิกัดอยู่ในประเทศญี่ปุ่นรหัส GeoNames ไม่ซ้ำจับคู่เมืองและจังหวัดตรงกันรักษาปีข้อมูลประชากร

รายการที่ไม่ผ่านในรอบล่าสุด

เก็บรายการที่จับคู่ไม่ได้ไว้ตรวจสอบ โดยไม่เดาว่าตรงกับเมืองใด

แหล่งข้อมูลชื่อเมืองเหตุผล

แสดงสูงสุด 100 รายการ ดูบันทึกทั้งหมดได้ในตาราง rejected_records ของ PostgreSQL

ที่มาและการอ้างอิง

สามแหล่งข้อมูลในชุดเดียว

ตรวจสอบที่มาได้ ใช้ขอบเขตพื้นที่สอดคล้องกัน และไม่สร้างค่าข้อมูลขึ้นเอง

e-Stat

ข้อมูลสำมะโนหลัก

ใช้ API แบบ JSON สาธารณะของระบบสถิติรัฐบาลญี่ปุ่น รหัสตัวชี้วัด 0201010000000010000 ปี ค.ศ. 2020 เชื่อมชื่อเมืองกับรหัสเทศบาลและจังหวัดจากข้อมูลพื้นที่ เลือกเฉพาะเทศบาลเมืองที่ชื่อลงท้ายด้วย -shi

เปิดระบบสถิติรัฐบาลญี่ปุ่น ↗
UNdata

ข้อมูลสำหรับเปรียบเทียบ

ดึงตาราง HTML ด้วย requests และ BeautifulSoup จากสถิติประชากรตาราง 240 เลือกประเทศญี่ปุ่น ปี 2020 ประชากรรวมทุกเพศ และขอบเขตตัวเมือง เก็บข้อมูลครบทุกหน้า หากชื่อซ้ำ ต้องจับคู่ได้เมืองเดียว หรือมีประชากรปีเดียวกันตรงกับ e-Stat เพียงเมืองเดียว

เปิดตารางประชากร UNdata ↗
GeoNames

ข้อมูลพิกัดอ้างอิง

ดึง HTML หน้าค้นหาเทศบาลเมืองญี่ปุ่น ไม่รวมเขตที่ยกเลิกแล้ว เขตย่อย ตำบล หมู่บ้าน และจังหวัด พิกัดเป็นจุดอ้างอิงเทศบาล ไม่ใช่เส้นขอบเขตเมือง แหล่งนี้ไม่ได้ระบุปีสำรวจประชากรไว้ในข้อมูลที่ใช้

วิธีการ

รวมข้อมูลอย่างไร

ปรับเครื่องหมายกำกับเสียงและคำลงท้ายชื่อเมือง แล้วจับคู่เมืองกับจังหวัดให้ตรงกัน ใช้รหัส GeoNames เป็นรหัสหลัก เก็บประชากรแยกตามแหล่งและปี เลือก e-Stat ก่อน UNdata และ GeoNames ตามลำดับ โดยไม่เฉลี่ยค่าประชากรที่ต่างกัน

ตรวจ robots.txt และจำกัดความถี่ทุกครั้งที่รวบรวม เก็บข้อมูลดิบ เวลาดึง และค่า SHA-256 ไว้ตรวจสอบ หากไม่ผ่านคุณภาพจะยังคงใช้ชุดข้อมูลที่เผยแพร่สำเร็จล่าสุด
